# Hermes Forge interactive demo

A free static demonstration of the Forge workflow. All bundled business data is fictional. Edits stay in browser storage. Generation, chat and scenarios use scripted templates; no AI model, grader, connected account or installer runs. No credentials can be entered through this demo.

Open the published GitHub Pages URL to try Brief, Soul, Skills, Connect, Test, Deploy and Verify / Export. Download a sample design as JSON. For private credentials and real deployments, use the full local Forge app.

This repository contains only the generated public demo, not client data or the local server.
